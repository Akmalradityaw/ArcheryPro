4. Fitur Web Portal (Laravel 10)

Antarmuka berbasis Blade dan Tailwind CSS untuk pengelolaan administratif dan rekapitulasi pelatih:

  • Manajemen Sesi Latihan: Pembuatan jadwal latihan baru, status latihan (Terjadwal, Berlangsung, Selesai), dan fitur duplikasi jadwal ke pekan berikutnya.
  • Form Input Skor Multi-Atlet: Formulir penilaian per-end yang memungkinkan pengisian skor beberapa atlet secara simultan.
  • Analisis Atlet & Ekspor: Melihat grafik perkembangan, moving average, serta ekspor laporan performa ke format Excel dan PDF.
  • Pengaturan Privasi Publik: Toggle administrator untuk mengizinkan atau menonaktifkan leaderboard publik bagi pengunjung umum.

6. Penilaian Lapangan & Offline Draft

Komponen InputSkorScreen.js menyediakan alur kerja terpadu untuk pencatatan tembakan:

Alur Kerja Penilaian:
  1. Pilih sesi latihan mingguan aktif dari tab carousel horizontal.
  2. Pilih atlet sasaran (bisa pilih lebih dari satu atlet untuk mode pelatih).
  3. Tentukan jarak tembak (default 30m) dan tanggal sesi.
  4. Tekan tombol keypad (X, 10, 9..M) — nilai langsung terisi ke slot panah aktif dan otomatis berpindah ke panah berikutnya.
  5. Subtotal end dan akumulasi total sesi terhitung seketika tanpa jeda request jaringan.
  6. Tekan "Simpan Skor Sesi" untuk mengirim data ke REST API. Jika jaringan sedang offline, tekan "Draft Lokal".

7. Analisis Performa & Stabilitas Atlet

Sistem menghitung metrik evaluasi objektif untuk membantu pelatih menilai kesiapan atlet:

Metrik Analisis Formula / Metode Interpretasi Pelatih
Moving Average (MA-4) Rata-rata bergerak 4 sesi latihan berurutan Melihat tren kenaikan atau penurunan performa tanpa terpengaruh fluktuasi satu sesi.
Standar Deviasi (≤ 2.2) Dispersi skor antar-end pada sesi terakhir Sangat Stabil Form tarikan, anchor, dan rilis sangat konsisten.
Standar Deviasi (2.3 - 4.0) Dispersi skor antar-end pada sesi terakhir Konsisten Kondisi tembakan teratur dengan sedikit variasi tembakan lepas.
Standar Deviasi (> 4.0) Dispersi skor antar-end pada sesi terakhir Perlu Perbaikan Rilis atau posisi anchor atlet belum ajeg.
Lencana Motivasi (Badges) Pencapaian sesi, volume panah (300+), dan akurasi (250..300) Meningkatkan motivasi latihan mandiri dan disiplin kehadiran atlet.

Seluruh endpoint mengembalikan format JSON terstandarisasi melalui ApiResponse.php dengan struktur seragam:

  "message": "Pesan status keberhasilan",
  "data": [ ... ],

    "current_page": 1,

Method Endpoint Otorisasi Deskripsi Singkat
POST /api/v1/auth/login Publik Login akun & mengembalikan token Bearer Sanctum
GET /api/v1/auth/me Bearer Token Profil user, relasi atlet, dan verifikasi token
POST /api/v1/auth/logout Bearer Token Pencabutan token Sanctum aktif
GET /api/v1/sesi-latihan Bearer Token Daftar sesi latihan (paginasi 10 data, filter status)
GET /api/v1/sesi-latihan/{id} Bearer Token Detail sesi latihan, agregat statistik & ranking atlet
GET /api/v1/atlet Bearer Token Daftar atlet aktif untuk pilihan input skor lapangan
POST /api/v1/skor Bearer Token Menyimpan tembakan multi-atlet & evaluasi pelatih
GET /api/v1/atlet/{id}/performa Bearer Token Statistik ringkasan, moving average, stabilitas & badges
GET /api/v1/atlet/{id}/riwayat Bearer Token Riwayat sesi latihan atlet (paginasi 10 item per halaman)
POST /api/v1/sesi/{sesi}/baca-catatan Bearer Token Menandai catatan evaluasi pelatih telah dibaca atlet
POST /api/v1/sesi/{sesi}/catatan Pelatih/Admin Menambahkan/memperbarui catatan evaluasi sesi atlet
PUT /api/v1/atlet/privasi Atlet Mengubah izin tampil pada papan peringkat publik
GET /api/v1/public/leaderboard Publik Papan peringkat umum (hanya atlet yang opt-in)
GET /api/v1/public/sesi-latihan Publik Jadwal latihan mingguan terbuka untuk umum

9. Panduan Menjalankan Sistem Secara Lokal

Pastikan Apache dan MySQL di XAMPP telah menyala pada komputer Anda.

Langkah 1: Menjalankan Backend Laravel

Buka terminal PowerShell pada direktori backend:

cd c:\xampp\htdocs\Non-Production\ArcheryPro\web
php artisan serve --host=0.0.0.0 --port=8000
Penting: Parameter --host=0.0.0.0 diperlukan agar HP fisik atau emulator dapat mengakses backend melalui jaringan WiFi yang sama di alamat IP laptop (http://192.168.1.4:8000).

Langkah 2: Menjalankan Frontend Mobile Expo

Buka terminal PowerShell baru pada direktori mobile:

cd c:\xampp\htdocs\Non-Production\ArcheryPro\mobile
npm start
  • Uji di HP Fisik (Rekomendasi): Buka aplikasi Expo Go di HP Android/iOS, lalu scan QR code terminal. Aplikasi otomatis mendeteksi IP WiFi PC (192.168.1.4).
  • Uji di Browser PC: Tekan tombol w pada terminal Expo untuk membuka di browser.
  • Uji di Android Emulator: Tekan tombol a pada terminal Expo.

10. Riwayat Masalah Teknis & Solusi Nyata (v1.0.0)

Dokumentasi kendala nyata yang ditemukan selama pengembangan versi 1.0.0 beserta solusi kodenya:

Kendala / Pesan Error Penyebab Teknis Solusi yang Telah Diterapkan
Fetch request has been canceled Server Laravel di port 8000 belum menyala atau HP mencoba menghubungi IP loopback (10.0.2.2 / localhost). Menjalankan backend dengan --host=0.0.0.0 dan menerapkan auto-detection IP host via NativeModules.SourceCode.scriptURL pada mobile/src/services/api.js.
Skor atlet di luar pilihan checkbox Objek state scores membawa kunci atlet yang sempat dicentang lalu dibatalkan. Menyaring cleanSkor di frontend sesuai selectedAtletIds dan menambahkan prepareForValidation() di StoreSkorRequest.php.
Duplicate entry uniq_sesi_atlet Tabel sesi menggunakan SoftDeletes, namun MySQL unique constraint tetap mendeteksi baris soft-deleted. Menggunakan Sesi::withTrashed()->where(...) dan melakukan $sesi->restore() pada SkorService.php, serta forceDelete() saat pembersihan data seeder.
Class App\Models\Pengaturan not found Pengaturan sistem tersimpan di model PengaturanSistem, bukan Pengaturan. Menyelaraskan impor dan pemanggilan fungsi ke PengaturanSistem::getValue() di PublicController.php.
Cannot read properties of undefined (reading 'data') Komponen mobile mengakses res.data.data, padahal trait ApiResponse menempatkan array langsung di res.data. Menstandarkan ekstraksi data dengan sintaks aman: Array.isArray(res?.data) ? res.data : (res?.data?.data || []).
