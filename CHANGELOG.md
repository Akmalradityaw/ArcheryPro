## [1.0.0] - 2026-09-29

### Added
- Laravel 10 REST API v1 with Sanctum authentication (14 endpoints).
- React Native Expo SDK 57 mobile client for field scoring.
- Interactive X..M archery scoring keypad with auto-advance.
- Offline draft support via AsyncStorage (multi-athlete).
- Weekly training session module.
- Athlete performance analytics (MA-4 / SD stability).
- Public leaderboard endpoint.
- Role-based navigation (admin / coach / atlet).
- Standalone technical documentation portal.
- Excel & PDF export for session reports.

### Security
- Sanctum token-based auth with expiration.
- Enforce HTTPS-only API in production.
